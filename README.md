# 劳动法学习工具

使用 Python 3.10 或以上，在本目录的虚拟环境中安装 requirements.txt，然后运行 python app.py。程序默认监听 127.0.0.1:8765。DeepSeek 密钥填入 deepseek.local.json 的 api_key 字段。已安装同版本 npm CLI 时，可设 LABOR_DSH_BIN 为 dsh 的绝对路径。

提交时一并选择案件文字、诉求和材料，确认后发送。每次成功分析的提交文本、附件原件和完整建议保存在当前浏览器、当前端口的 IndexedDB。重新打开可恢复，清除网站数据会删除记录；后续提交带入最近八次陈述、最新摘要、上次建议及其材料编号，历史文本最多 48000 字符。每次检索官方网页，随后将来源、历史、最新文字和材料交给 DeepSeek Harness。

图片作为视觉输入。视频取四个时间位置的画面，音轨和录音按最多110秒分段提交 DeepSeek ASR。多媒体处理需要 ffmpeg 和 ffprobe。文本 PDF 使用 pdftotext，Word 使用 macOS textutil。扫描 PDF 可提交页面图片。单次材料合计最多32 MB，单个影音文件最长30分钟。模型输出中的法条和案例引用在服务端核验。

当前分析先展示新材料对判断的影响，再按主张列出材料定位、支持的事实、证据缺口和官方引用。其余检索结果默认折叠。官方案例检索读取深圳市人社局公开裁决目录的首页和下一页，最多40篇。
